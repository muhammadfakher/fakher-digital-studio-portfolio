# Fakher Nadeem Portfolio

One-page portfolio for Fakher Nadeem, focused on video editing, graphic design, and AI video storytelling.

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Checks

- `npm test` checks the portfolio content and local video assets.
- `npm run build` creates the production build.

The portrait and four playable video samples are included under `public/`. The existing Vercel deployment was not changed by this local project update.
